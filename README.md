# AI Learning Companion

## GitHub Pages

This repository is configured to deploy automatically to GitHub Pages whenever changes are pushed to `main`.

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Set **Source** to **GitHub Actions**.
4. Push to `main` (or run **Deploy to GitHub Pages** from the Actions tab).

The workflow supports both a plain static prototype (`index.html` at the repository root) and Node-based projects that produce a `dist/` or `build/` directory.
